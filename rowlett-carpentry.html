Questions for this project

Which records are useful after the project is complete?

Keep the final scope, approved changes, product labels or model numbers, care information, manufacturer warranty documents and completion photographs. Record the responsible contact for each product and installation issue.

What needs to be confirmed before carpentry begins?

Keep the approved sample with the work order. The written scope should also identify the selected products, work boundaries, required trade coordination and approval steps for changes.

Are the listed manufacturers included in every estimate?

Carpentry FAQ

Do you handle both finish carpentry and framing repairs?

Yes. A project can include visible finish work such as trim and doors as well as framing repairs, blocking and wall modifications when required by the approved scope.

Can you match existing trim profiles?

We inspect the existing profile and source the closest practical match. When an exact profile is unavailable, we explain the available options before installation.

Can you install prehung and slab doors?

Yes. Door work can include prehung units, slab replacement, casing, hardware, alignment and finish preparation, depending on the opening and project conditions.

Do you build custom shelves or built-ins?

Yes. We can build or install shelving, storage, cabinet components and other practical built-in features based on measurements, materials and the final design.

Can carpentry repairs be included in a larger remodel?

Yes. Carpentry can be coordinated with drywall, painting, flooring, cabinets, doors and other trades so the work is completed as one organized project.
