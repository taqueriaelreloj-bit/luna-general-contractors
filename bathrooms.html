Bathroom remodeling: materials, methods and a clear scope.

Plan the bathroom as an assembly: layout, plumbing, waterproofing, ventilation, tile, glass and storage need compatible details.

A shower conversion starts with the existing floor

Replacing a tub with a shower changes the drain, base and waterproofing geometry. The scope should establish framing and plumbing conditions before choosing the pan, tile layout or final enclosure dimensions.

Work in an occupied property

If the property remains in use, agree on protected routes, room access, material storage and the point at which each area can be used again. The work plan should identify who moves belongings and how the construction area is separated.

Schluter KERDI

Bonded sheet waterproofing

A sheet membrane can form the waterproof layer beneath a compatible tiled shower assembly.

Selection check
Seams, corners, penetrations, drain connections and the selected mortar must follow the system instructions. Tile and grout alone are not the waterproof layer.

Coverage and scope

KERDI membranes have a 10-year limited warranty; eligible complete-system programs may differ. Confirm all component and installation requirements.

Daltile

Ceramic and porcelain tile

Tile options differ in size, finish, water absorption and approved location. A wall-only tile is not automatically suitable for a floor.

Selection check
Review the exact tile’s use rating, wet-area suitability, substrate, grout and movement-joint requirements before selecting the pattern.

Coverage and scope

Daltile’s standard tile warranty is limited; specialty collections and system programs have separate terms. Request the exact product warranty.

Official reference →

KraftMaid

Factory-built cabinetry

Cabinet boxes, doors, drawers and storage accessories need to work with the room’s measured layout and appliances.

Selection check
Review fillers, finished end panels, support, hardware clearances and installation responsibility. Approve a physical door sample before ordering.

Coverage and scope

KraftMaid provides limited lifetime coverage for eligible residential cabinetry; commercial and other exclusions apply.

Questions for this project

How will access and protection work while the property is occupied?

Include a room sequence, daily access route, protection responsibilities and a handoff before each area is returned to use. Confirm these details against the actual scope rather than assuming every phase can happen around normal occupancy.

What needs to be confirmed before bathroom remodeling begins?

Confirm drain position and the waterproofing approach. The written scope should also identify the selected products, work boundaries, required trade coordination and approval steps for changes.
