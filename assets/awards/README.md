# Nextdoor Neighborhood Faves 2024

The unmodified JPG is the official 2024 printable sticker supplied in Nextdoor's winner marketing kit. It is displayed as a dated award, separately from Google review ratings.

- Official kit: https://business.nextdoor.com/hubfs/neighborhood-faves/Neighborhood_Faves_2024_-_Digital_Kit.pdf
- Download: https://business.nextdoor.com/hubfs/neighborhood-faves/Neighborhood_Faves_2024_-_Digital_Kit_-_Ads.zip
- Original file: `Neighborhood Faves 2024 - Digital Kit_Sticker.jpg`
- Luna award verification: https://nextdoor.com/page/luna-general-contractors-grand-prairie-tx/
- Luna's Nextdoor business profile displays the 2024 Fave Awards badge.

Run `node scripts/build-nextdoor-award.mjs` to apply the award beside existing review summaries. The customer review builder also runs this pass so regenerated pages retain the recognition.
